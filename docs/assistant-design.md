# Assistant-first design / v0.3.0
Goal: minimum typing, recommendations not game automation. Main view guides user to the next meaningful screen; catalog and manual forms are secondary. Capture reads only the RuneScape client with granted pixel permission. No game input or external upload. Native capture and legacy bound-image transfer follow the API and channel order documented in https://runeapps.org/apps/alt1/helpoutput.html and https://github.com/skillbert/alt1/blob/master/src/base/wrapper.ts . Real-client validation required. PNG export is a diagnostic capability, not normal end-user workflow; save only when deliberately requested. Existing Ports reader reference: https://github.com/Popoplo0/ports (Edit Ship > Edit Crew, hover and Alt+1). No source code reused from that repository. Next: validate sample pixels, read interface anchors and tooltips, deduplicate observations, flag uncertain fields, recommend actions based only on confirmed data. Never silently fill missing values from catalog or guessed OCR.
