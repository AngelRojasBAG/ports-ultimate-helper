# v0.4.8
Read-only Alt1 OCR lab replaces the mounted roster reader temporarily. Uses pinned npm alt1 0.1.3 browser UMD bundles and available packaged fonts; no runtime Tesseract invocation, no roster writes, no game clicks. Tesseract source/dependency intentionally preserved pending comparison, prebuild no longer prepares Tesseract assets during this experiment. Crop regions reuse previous geometry, scanning candidate baselines and colors; no automatic winner or claimed accuracy. Build verifies presence of OCR bundles and at least one font. Runtime compatibility, font coverage, crop accuracy and speed need testing in Alt1. Source: https://github.com/skillbert/alt1/tree/master/src/ocr and https://www.npmjs.com/package/alt1. No storage changes.
