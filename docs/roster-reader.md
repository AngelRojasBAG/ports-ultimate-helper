# v0.3.1 experimental reader
Based on user supplied 1920x1009 screenshot of Crew Roster. Native bindReadString fonts documented in https://github.com/skillbert/alt1/blob/master/src/base/alt1api.ts . Centered heading search and relative panel offsets are provisional, not universal anchor detection. No template recognition or crew grid enumeration yet. Native OCR may not recognize this font. Confirmed complete readings stored as separate observations, not merged into roster; identical observations deduplicated, distinct identical units not identifiable. No inputs sent to game. No screenshot upload. Tests cover text parsing, not recognition of real pixels.
