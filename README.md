# Ports Ultimate Helper
Asistente de Player-Owned Ports para RS3 y Alt1. Versión 0.1.0: diagnóstico de la API nativa de Alt1 y configuración local del puerto. No controla el juego ni captura imágenes en esta versión.

## Desarrollo
Node.js 22: `npm install`, `npm run dev`, `npm test`, `npm run build`.

## Publicación
Settings > Pages > Source: GitHub Actions. El workflow compila, prueba y publica desde main.

## Instalación (después de despliegue exitoso)
https://angelrojasbag.github.io/ports-ultimate-helper/

Manifest: https://angelrojasbag.github.io/ports-ultimate-helper/appconfig.json

La interfaz muestra si Alt1 está presente y si los permisos están concedidos. Validar en Windows con RuneScape abierto. El icono SVG y el formato de permisos requieren comprobación en Alt1 real.
